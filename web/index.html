Capabilities & boundaries

Runtime containers have no direct Internet route. Governed HTTPS fetches run through the outer worker. The package downloader uses a separate bridge-network helper; that helper is not egress-isolated. Package install scripts execute inside the bot environment.

An allowlist is permission for future tool calls, not proof that software is installed or a site is reachable.

Operator allowlists

Loading policy…

Exact Debian package names, one per line. Empty denies every package install.

Exact lowercase DNS hostnames, one per line. No schemes, paths or wildcards. Empty denies all governed fetches.

Save only packages and destinations you explicitly trust for this bot. This local operator policy is separate from the bot’s instructions.

Telegram readiness

Checking configured channel…

Operator setup notes

Configure Telegram only in the outer host’s private server configuration. Keep the bot token out of this dashboard and out of task prompts. Enable private long-polling, bind one permitted private chat and sender to the intended Chestnut bot, then start the dedicated channel process alongside the worker.

See docs/telegram-channel.md in the repository before enabling. Configured status is not a delivery test; the channel’s last-seen and delivery states are shown above. This dashboard does not create connections or send a test message.

Scheduled work

Loading schedules…

Schedules queue ordinary tasks for the worker. Missed cron runs coalesce into one; overlapping runs of the same schedule are skipped. Paused cron intervals are not replayed. Daylight-saving gaps are skipped and repeated local times fire once.

Displayed run timestamps use your browser’s time zone. One-time creation below uses UTC; cron uses its named IANA zone.

Add scheduled task

Enter UTC, not your computer’s local time.

Five fields: minute, hour, day, month, weekday.
